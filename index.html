사용 방법

  1. 열기받은 링크를 PC의 Chrome 또는 Edge로 엽니다. 메신저 안에서 열리면 「기본 브라우저로 열기」를 눌러 주십시오.
  2. 도구 고르기위 카드에서 도구를 엽니다. 도구 화면 위쪽 「처음 화면」이나 브라우저 뒤로 가기로 이 화면에 돌아옵니다. 글자 크기·밝기는 오른쪽 위 버튼으로 바꿉니다.
  3. 음성질문·고객 대사 읽기는 PC에 설치된 한국어 음성으로 처리합니다(외부 전송 없음). 소리가 안 나면 스피커와 Windows 음성 설정을 확인하십시오. 휴대폰보다 PC 사용을 권장합니다.
  4. 기록 남기기 (선택)대화 내용은 저장되지 않으며, 창을 닫으면 사라집니다. 기록이 필요할 때만 마지막 단계의 「기록 파일로 저장」을 누르십시오.
